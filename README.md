# سیستم تحلیل جامع بازارگردانی بهگزین

## 📋 توضیحات پروژه

این سیستم یک پلتفرم تحلیل مالی جامع برای مدیریت پرتفوی بازارگردانی است که تحلیل بنیادی کامل، ارزش‌گذاری چند سناریویی و تحلیل تخصیص منابع را برای 9 نماد بورسی ارائه می‌دهد.

### 🎯 هدف
کمک به مدیریت بهینه منابع بازارگردانی با ارائه تحلیل‌های داده‌محور برای تصمیم‌گیری در مورد تخصیص منابع مالی بین نمادهای مختلف.

### 📊 نمادهای تحت پوشش

**نمادهای با مازاد منابع:**
- 🟢 زفجر - 🟢 کاوه - 🟢 گکوثر

**نمادهای با کمبود منابع:**
- 🔴 رنیک - 🔴 قشیر - 🔴 زدشت - 🔴 وسنا - 🔴 کگاز - 🔴 تلیسه

## ⭐ ویژگی کلیدی: استفاده از قیمت تعدیل شده

این سیستم **از قیمت‌های تعدیل شده استفاده می‌کند** که شامل:
- تعدیل افزایش سرمایه (Stock Splits)
- تعدیل تقسیم سود نقدی (Dividends)
- سایر تعدیلات شرکتی

با استفاده از `finpy-tse` و فعال کردن پارامتر `adjust_price=True`

---

## 📦 ماژول‌ها

### 1. استخراج داده‌های قیمتی (`price_data_extractor.py`)
```python
from src.price_data_extractor import PriceDataExtractor

extractor = PriceDataExtractor()
df = extractor.get_symbol_price_history(
    symbol='زفجر',
    start_date='1402-01-01',
    adjust_price=True  # قیمت تعدیل شده ⭐
)
```

### 2. تحلیل بنیادی (`fundamental_analysis.py`)
- نسبت‌های نقدینگی، سودآوری، اهرمی، فعالیت
- تحلیل روند اقلام مالی
- امتیاز سلامت مالی

### 3. ارزش‌گذاری (`valuation.py`)
- DCF, P/E, P/B, EV/EBITDA, P/S
- 3 سناریو: خوشبینانه، خنثی، بدبینانه

### 4. تخصیص منابع (`resource_allocation.py`)
- رتبه‌بندی اولویت‌ها
- امتیازدهی چند معیاره
- توصیه‌های عملیاتی
